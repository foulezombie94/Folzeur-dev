# Folzeur

Folzeur est un éditeur de code extensible pour Windows, macOS et Linux. Il fournit les outils nécessaires pour éditer, construire et déboguer des projets.

Le projet est distribué sous licence MIT. Consultez [LICENSE.txt](LICENSE.txt) et [ThirdPartyNotices.txt](ThirdPartyNotices.txt) pour les conditions applicables au code source et aux dépendances.

## Développement

Installez les dépendances puis lancez la compilation :

```bash
npm install
npm run compile
```

Pour le développement en continu :

```bash
npm run watch
```

## Extensions
